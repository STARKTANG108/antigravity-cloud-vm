# Antigravity 2.29 Cloud VM Workspace (`antigravity-cloud-vm`)

专用于 **Google Antigravity 2.29 Remote Agents（云端远程智能体 / 独立云端虚拟机）** 的挂载工作区仓库。

## 快速使用

在 Antigravity 桌面端或网页端（https://antigravity.google.com/remote）绑定本仓库（`STARKTANG108/antigravity-cloud-vm`）后：

- **一键查看云端虚拟机配置（CPU / 内存 / 磁盘 / 工具链）**：
  直接在对话框发送：
  ```text
  体检
  ```
  或运行：
  ```bash
  bash ./check-vm.sh
  ```
